## 6. 개발 패턴

### 컴포넌트 구조
- 훅을 사용하는 함수형 컴포넌트 작성
- Props에 적절한 TypeScript 타입 정의
- 단일 책임 원칙 준수
- 컴포넌트는 작고 집중된 역할만 수행

### 상태 관리
- 로컬 상태는 React 훅(useState, useReducer) 사용
- 공유 상태는 Context API 활용

### 에러 처리
- Error Boundary 구현
- 비동기 작업에 try-catch 사용
- 사용자 친화적인 에러 메시지 제공

### Nullable Prop 처리
**원칙: `null`/`undefined` 타입을 자식 컴포넌트까지 드릴링하지 말고, 한 층 위(경계)에서 풀어버린다.**

자식 props에 `?.`, `?? ''`, `?? undefined`, `disabled={x === null}`가 반복되면 nullable이 잘못된 레이어까지 흘러간 신호다.

- **부모에서 가드 후 자식 렌더 (기본 선택지)**: 데이터가 준비될 때까지 자식을 렌더하지 않고, 자식 props는 non-nullable로 좁힌다.
- **`null`/`undefined` 통일**: "값 없음"은 `undefined`, "의도적 빈 값"은 `null`. 변환(`?? undefined`)이 보이면 소스(hook/api)에서 통일한다.
- **Context는 Provider 레벨에서 검증**: `useXxx` 훅 안에서 미초기화면 throw → consumer는 non-null로 다룬다.
- **불필요한 기본값 prop 지양**: `selected = DEFAULT_OPTION` 같은 기본값은 호출자가 항상 값을 제공한다면 제거하고 필수 prop으로 만든다.

**검증 기준:** props에 `| null`이나 `?:`가 있다면 "이 컴포넌트가 정말 그 부재 상태를 직접 처리해야 하는가?"를 자문한다. 아니라면 호출자에서 가드한다.

## 8. 프로젝트 파일 구조

```
├── src/
│   ├── api/                        # API 호출 함수
│   ├── assets/                     # 이미지, 폰트 등 정적 자원
│   ├── claude/                     # 클로드 파일
│   ├── components/                 # 아토믹 디자인 컴포넌트
│   │   ├── atoms/                  # 최소 단위 UI (Button, Input 등)
│   │   ├── molecules/              # atoms 조합 (SearchBar 등)
│   │   ├── organisms/              # molecules 조합 (Header, CardList 등)
│   │   └── templates/              # 페이지 레이아웃 틀
│   ├── contexts/                   # Context API 상태 관리
│   ├── data/                       # 참조용 정적 데이터 자원
│   ├── hooks/                      # 커스텀 훅
│   ├── pages/                      # 라우트별 페이지 컴포넌트
│   │   └── home/                   # 예제용 Home Page
│   │       ├── index.tsx           # 페이지 진입점
│   │       ├── Home.tsx            # 메인 컴포넌트
│   │       ├── Home.css            # 페이지 전용 css
│   │       ├── components/         # 페이지 전용 컴포넌트
│   │       └── hooks/              # 페이지 전용 훅
│   ├── test/                       # 테스트 설정
│   ├── types/                      # TypeScript 타입 정의
│   ├── utils/                      # 유틸리티 함수
│   ├── App.tsx                     # 라우터 및 Provider 설정
│   ├── index.css                   # Tailwind 글로벌 스타일
│   ├── main.tsx                    # 앱 진입점
```
